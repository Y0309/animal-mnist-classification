# Selected Animal-MNIST Figures

These are the distinct figures selected for the project repository. Upload these files inside the repository's existing `results/` folder.

- `per_class_test_accuracy.png`: class-level test accuracy for all three models.
- `test_accuracy_comparison.png`: overall test accuracy comparison.
- `logistic_regression_confusion_matrix.png`, `mlp_confusion_matrix.png`, `cnn_confusion_matrix.png`: confusion matrices for each model.
- `cnn_validation_accuracy.png`: CNN validation accuracy over training epochs.
- `cnn_training_loss.png`: CNN training loss over epochs.
- `mlp_training_loss.png`: MLP training loss over epochs.
- `animal_mnist_examples.png`: sample images from the dataset.

Duplicate copies of the same charts were intentionally left out.
